Every data lab ships its dataset in `labs/<lab>/data/` — CSV, plus an XLSX workbook where a
spreadsheet is the natural tool. Each `data/README.md` documents the files and the defects
planted in them. Learners download the data in the first step of the lab; nothing is typed in.

### Lab environment

| Tool | Used for |
|---|---|
| **[Killercoda Ubuntu Playground](https://killercoda.com/playgrounds/scenario/ubuntu)** | Browser Ubuntu terminal with Python 3, pandas and SQLite |

| **[Cybersecurity Threat Simulator](https://alfredang.github.io/cybersecuritysimulator/)** | Data-leakage risk scoring and classification reasoning for the governance domain |

### Lesson Plan

5 training days · 9:00 am – 6:00 pm · 8 instructional hours per day (1-hour lunch;
tea breaks counted within training time) · **40 hours total**
(19 h classroom facilitation + 19 h practical + 2 h assessment).

| Day | Theme |
|---|---|
| 1 | Data Concepts, Schemas and Environments |
| 2 | Data Acquisition, Exploration and Preparation |
| 3 | Data Analysis — Descriptive and Inferential Statistics |
| 4 | Visualization, Dashboards and Reporting |
| 5 | Data Governance, Quality, Controls and Final Assessment |

**Assessment** (Day 5, 4:00 – 6:00 pm, open book):
Written Assessment (SAQ) 1 hour covering K1–K4, then Practical Performance 1 hour covering A1–A5.
