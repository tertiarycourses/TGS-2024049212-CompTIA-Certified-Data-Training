## How to Use

1. Open the learner guide first and review the sample dataset and data ethics checklist.
2. Complete the labs in order because later analysis and dashboard labs reuse cleaned data from earlier labs.
3. Use Excel, LibreOffice Calc, Google Sheets, SQLite, Power BI Desktop, Tableau Public, or other trainer-approved tools.
4. Save intermediate files after each lab so you can compare raw, cleaned, analyzed, and presented data.
5. Record assumptions, formulas, queries, charts, and data quality decisions in your lab journal.
