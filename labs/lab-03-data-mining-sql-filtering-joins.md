# Lab 03 - Data Mining with SQL, Filtering, and Joins

## Objectives

- Write simple SQL queries.
- Filter and sort data.
- Group and aggregate records.
- Join related tables.

## Steps

1. Load the cleaned dataset into SQLite or use a trainer-provided database.
2. Run `SELECT * FROM orders LIMIT 10;`.
3. Select only needed columns.
4. Filter records with `WHERE`.
5. Sort records with `ORDER BY`.
6. Group records with `GROUP BY`.
7. Calculate `COUNT`, `SUM`, `AVG`, `MIN`, and `MAX`.
8. Create or use a reference table.
9. Join the main table to the reference table.
10. Export the query result.
11. Save all SQL queries in a text file.

## Validation

- Queries run without errors.
- Filters match the business question.
- Aggregations use correct grouping.
- Join does not unexpectedly duplicate rows.

## Review Questions

1. What does `WHERE` do?
2. Why use `GROUP BY`?
3. What can go wrong with joins?
4. Why save SQL queries?
