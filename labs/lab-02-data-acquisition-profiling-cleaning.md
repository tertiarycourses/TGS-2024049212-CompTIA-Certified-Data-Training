# Lab 02 - Data Acquisition, Profiling, and Cleaning

## Objectives

- Import data safely.
- Profile data quality.
- Clean common issues.
- Save a cleaned dataset.

## Steps

1. Save a read-only copy of the raw dataset.
2. Import the dataset into your spreadsheet or database tool.
3. Count rows and columns.
4. Check data types.
5. Identify missing values.
6. Identify duplicate rows.
7. Identify inconsistent categories.
8. Identify invalid dates or impossible values.
9. Create a cleaning log.
10. Standardize category spelling and capitalization.
11. Format dates consistently.
12. Remove, flag, or retain duplicates based on trainer guidance.
13. Decide how to handle missing values.
14. Save the cleaned dataset separately.

## Validation

- Raw data remains unchanged.
- Cleaning log explains each change.
- Missing and duplicate handling is documented.
- Cleaned dataset is saved separately.

## Review Questions

1. Why preserve raw data?
2. What is the risk of deleting rows too quickly?
3. How can inconsistent categories affect charts?
4. Why should cleaning decisions be documented?
