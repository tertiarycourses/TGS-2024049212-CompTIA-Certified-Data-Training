# Lab 06 - Visualization, Chart Selection, and Dashboard Design

## Objectives

- Choose appropriate charts.
- Build clear visuals.
- Create a simple dashboard.
- Apply readability checks.

## Steps

1. Select four findings from Lab 05.
2. Choose a chart type for each finding.
3. Build a bar chart for category comparison.
4. Build a line chart for time trend.
5. Build a table or KPI card for precise values.
6. Add clear titles, labels, and units.
7. Use consistent colors.
8. Avoid unnecessary decoration.
9. Add filters if your tool supports them.
10. Arrange charts into a dashboard.
11. Add one insight sentence per chart.
12. Export or screenshot the dashboard.

## Validation

- Chart types match analytical needs.
- Labels are readable.
- Dashboard has clear visual hierarchy.
- Insights are supported by the visuals.

## Review Questions

1. When is a bar chart better than a pie chart?
2. Why are labels and units important?
3. What makes a dashboard cluttered?
4. How can color mislead readers?
