# Lab 01 - Data Concepts, Environments, and Dataset Inventory

## Objectives

- Classify data types.
- Identify data sources and environments.
- Build a data dictionary.
- Document metadata.

## Steps

1. Open the sample dataset.
2. List every field name.
3. Write a plain-language meaning for each field.
4. Classify each field as numeric, text, date/time, Boolean, categorical, or identifier.
5. Identify whether the dataset is structured, semi-structured, or unstructured.
6. Identify possible data sources.
7. Record sample values and units.
8. Identify primary key candidates.
9. Identify duplicate risk.
10. Draw a simple data flow from source to report.
11. Note where the data might be stored: file, database, warehouse, lake, or application.

## Validation

- Every field has a definition.
- Data types are classified correctly.
- Key and duplicate risks are documented.
- Data flow is understandable.

## Review Questions

1. Why is metadata important?
2. What is the difference between structured and semi-structured data?
3. Why do identifiers need special handling?
4. What makes a good data dictionary?
